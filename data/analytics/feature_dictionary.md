# Feature Dictionary

This document details all engineered features added to the e-commerce datasets during the ETL phase. These features are designed to facilitate deeper analytical insights such as Cohort Analysis, Customer Lifetime Value (CLV) modelling, and margin optimizations.

## 1. Item-Level Features (Profitability)
Located in `fact_order_items.csv` and the Analytical Master Table.

| Feature Name | Data Type | Description | Formula |
|---|---|---|---|
| `gross_profit` | Float | The total margin generated from this line item after factoring in the quantity and the applied discount. | `line_total - (quantity * unit_cost)` |
| `gross_margin_pct` | Float | The percentage of the final sale price that is profit. A value of `0.0` indicates break-even, and negative values indicate a loss-leader sale. | `gross_profit / line_total` (Rounded to 4 decimal places) |

## 2. Order-Level Features (Temporal)
Located in `fact_orders.csv` and the Analytical Master Table.

| Feature Name | Data Type | Description | Formula |
|---|---|---|---|
| `order_month` | Integer | The calendar month in which the order was placed (1 to 12). | Extracted from `order_date` |
| `order_quarter` | Integer | The calendar quarter in which the order was placed (1 to 4). | Extracted from `order_date` |
| `order_year` | Integer | The calendar year in which the order was placed. | Extracted from `order_date` |
| `order_weekday` | Integer | The day of the week in ISO format (1=Monday, 7=Sunday). | Extracted from `order_date` |
| `is_weekend_order` | Boolean | True if the order was placed on Saturday (6) or Sunday (7). | `order_weekday IN (6, 7)` |

## 3. Customer-Level Features (RFM & Retention)
Located in `dim_customers_enriched.csv` and the Analytical Master Table. All time-based calculations use a dynamic analysis reference date equal to the maximum `order_date` found in the dataset.

| Feature Name | Data Type | Description | Formula |
|---|---|---|---|
| `total_orders` | Integer | Lifetime count of completed orders (Frequency). | `COUNT(order_id)` where status = 'Completed' |
| `total_revenue` | Float | Lifetime gross revenue generated by the customer (Monetary Value). | `SUM(total_amount)` where status = 'Completed' |
| `first_purchase_date` | Datetime | The exact date of the customer's very first completed order. Critical for Cohort Analysis. | `MIN(order_date)` |
| `latest_purchase_date` | Datetime | The exact date of the customer's most recent completed order. | `MAX(order_date)` |
| `days_since_last_purchase` | Integer | The number of days elapsed since the customer's last purchase (Recency). | `(Analysis Date) - latest_purchase_date` |
| `customer_tenure_days` | Integer | The total lifetime age of the customer's account in days. | `(Analysis Date) - signup_date` |
| `purchase_frequency` | Float | The average number of orders per day of their tenure. A higher value indicates an extremely active purchaser. | `total_orders / customer_tenure_days` |
| `is_repeat_customer` | Boolean | Simple flag indicating whether the customer has made more than one purchase. | `total_orders > 1` |

## 4. Analytical Master Table (AMT)
The `analytical_master_table.csv` is a fully denormalized (flattened) dataset containing all features from Items, Orders, Products, Categories, Customers, and Dim Date. This is the primary table intended for ingestion into BI tools like Power BI or Tableau.
